## Learning Outcome

In this recipes project, I leveraged the power of the modern markup (HTML5) language to structure the webpage of recipes. Among the following are the relevant skills learned:

- Adding main headings to webpages. Every webpage should be given an important heading, as this specifies the page's main objective. This could be done by wrapping a text or group of texts in a h1 opening and closing tags. Every other heading decreases in importance, depending on the heading tag (i.e h2 to h6)

- Embedding images in webpages is a good practice, as this improves the visual effect of the pages. By declaring the img tag, one can easily add images to their webpages. This is possible by specifying the path to the images using the src attribute. It is also considered best practice to include alternative texts describing the image using the alt attribute. This is used by assistive technologies like screen readers to describe the image to visually-impaired users, improving accessibility of my site

- Navigating between webpages internally using hyperlinks also enables your users to have a general overview of what your site is all about and has to offer. Declaring the anchor (a) tag and specifying the path to the pages using the href attribute will enable your users to navigate your site seamlessly. It is good to notice that these pages should be relative to the main (home) page of your site. This main page is usually referenced by the "index.html" file and must always be at the root directory, as browsers serve this file by default when users request for your site.

- In order to prevent navigation links from being displayed in one line, an unordered list could be declared to list the links

- And to display numbered list of steps for preparing a recipe, an ordered list could be the best option to list the steps
